# Обратная связь

## Отзывы и пожелания

Пожалуйста, пишите в Twitter с хештегом `#AivisSpeech`. Это мотивирует нас продолжать разработку.

## Сообщения о неполадках и ошибках

Если что-то работает неправильно или вы обнаружили ошибку, свяжитесь с нами одним из следующих способов.

1. **Форма обратной связи (рекомендуется)**  
   Вы можете сообщить о проблеме через [форму обратной связи Aivis Project](https://docs.google.com/forms/d/e/1FAIpQLSd1gi8lMW1mpdrkCHbM090pWmWhKgz4tR1Obc9G9hOuWpZPsA/viewform).

2. **GitHub Issue**  
   Если у вас есть аккаунт GitHub, сообщение через [GitHub Issue](https://github.com/Aivis-Project/AivisSpeech/issues) позволит быстрее приступить к решению проблемы.

Чем больше из следующей информации вы приложите, тем быстрее мы сможем отреагировать.

- Описание неполадки
- Шаги воспроизведения (если есть видео или фотографии, приложите их)
- Тип ОС и версия AivisSpeech
- Что вы уже пробовали сделать для решения
- Наличие антивирусного ПО и т. п. (если это может быть связано)
- Текст отображённого сообщения об ошибке
- Журнал ошибок

> [!NOTE] Примечание
> Журнал ошибок можно посмотреть в AivisSpeech через «Справка / Как пользоваться → Обратная связь → кнопки „Открыть папку журналов“ и „Открыть папку журналов движка синтеза речи“».

> [!WARNING] Предупреждение 
> Журнал ошибок может содержать системную информацию, например имя пользователя ПК.  
> Предоставленные данные используются только для решения проблемы, а конфиденциальность строго защищается.
